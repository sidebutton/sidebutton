# SideButton 1.5.3

*2026-08-05 · npm + OSS tag v1.5.3*

## Jira app credential vending

Agents working tickets on a Jira site with the SideButton app installed receive their Jira credentials **from the app connection** — no per-agent API tokens to create and distribute. The credential is vended to the agent environment at dispatch and scoped to the connected site.

## Refreshed default knowledge pack

The vendored default pack ships agents 1.17.0, keeping first-run installs in step with the public catalog — the bundled copy is what seeds a fresh server before `sidebutton install agents` ever runs.
